# NorthPeak Talent Review — Live Room

A single-file HTML dashboard demonstrating a live-room talent-review workflow —
critical roles, successor pipelines, functional fit + step-in cover capture,
9-box calibration, retirement-horizon signals, cohort persona / trait analytics,
scenario modelling, and consolidated action tracking.

Uses fictitious data (NorthPeak Industries, its BUs and leader roster) — no
real-company data. Designed for demo, walkthrough, and configurable-tool
prototyping.

## Running

Open `index.html` in any modern browser — no build step, no server needed.

## Structure

- `index.html` — the entire application (HTML + CSS + JS), inline
- External dependencies (loaded via CDN): Chart.js, SheetJS/xlsx
